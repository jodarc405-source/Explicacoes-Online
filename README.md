# Matemática 360º - Treino Diário 10.º Ano

Aplicação Web autónoma para estudo diário de Matemática A (10.º ano), alinhada com o manual escolar *Matemática 360º* (Raiz Editora).

## Funcionalidades
1. **Sessão Diária de 60 Minutos:**
   - 8 exercícios estruturados (cotação de 2,5 valores cada, totalizando 20 valores).
   - Cronómetro decrescente em tempo real.
   - Filtro por domínio: Lógica e Conjuntos, Geometria Analítica, Funções e Gráficos, Estatística ou Revisão Geral.

2. **Ficha de Avaliação A4 (Impressão para Resolução Manuscrita):**
   - Cabeçalho escolar oficial com campos para Nome, Turma, N.º, Data e grelha de classificação.
   - Espaço quadriculado/milimétrico entre itens para realização de cálculos manuscritos.

3. **Correção Imediata e Resolução Integral:**
   - Atribuição de nota de 0 a 20 valores após submissão.
   - Demonstrações analíticas e critérios de correção passo a passo.
   - Opção para imprimir a ficha completa de resolução.

4. **Dashboard de Desempenho:**
   - Gráfico temporal de evolução das notas (Chart.js).
   - Gráfico de radar (teia) com percentagem de domínio nos 4 módulos.
   - Contador de streak diário e total de horas de estudo acumuladas.
   - Diagnóstico automático com recomendações direcionadas às páginas do manual.

## Como Executar
Abra diretamente o ficheiro `index.html` em qualquer navegador web (Google Chrome, Edge, Firefox). Não requer servidor ou instalação de dependências.
